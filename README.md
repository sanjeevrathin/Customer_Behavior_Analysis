
# 🛍️ Customer Behavior Analysis

## 📌 Project Overview

Customer Behavior Analysis is an end-to-end data analytics project that explores customer purchasing patterns using **Python**, **MySQL**, and **Power BI**. The project focuses on cleaning and analyzing retail customer data to uncover actionable business insights through SQL queries and interactive dashboards.

---

## 🎯 Objectives

- Analyze customer purchasing behavior.
- Identify top-performing products and categories.
- Evaluate the impact of discounts on sales.
- Understand customer demographics and spending patterns.
- Build an interactive Power BI dashboard for business decision-making.

---

## 🛠️ Tech Stack

- **Python** (Pandas)
- **MySQL**
- **Power BI**
- **Jupyter Notebook**
- **VS Code**

---

## 📂 Project Workflow

### 1. Data Collection
- Imported customer shopping behavior dataset.
- Verified data quality and structure.

### 2. Data Cleaning (Python)
- Removed duplicate records.
- Checked for missing values.
- Corrected data types.
- Prepared data for analysis.

### 3. SQL Analysis
Performed business analysis using SQL:
- Revenue analysis
- Customer segmentation
- Product category analysis
- Discount analysis
- Review rating analysis
- Top-selling products
- Purchase trends
- Window Functions
- Common Table Expressions (CTEs)
- Aggregate Functions
- Subqueries

### 4. Dashboard Development
Created an interactive Power BI dashboard containing:
- Revenue KPIs
- Customer demographics
- Sales by category
- Product performance
- Purchase trends
- Review rating insights
- Interactive filters and slicers

---

## 📊 Key Business Insights

- Total revenue generated by gender.
- Top 3 purchased products in each category.
- Best-performing product categories.
- Average purchase amount by customer segment.
- Effect of discounts on customer purchases.
- Highest-rated products.
- Customer shopping trends across categories.
